# Online Shoe Store Webpage

This is an online shoe store webpage built using React, featuring user authentication, a shopping cart, and cache memory for improved performance.

## Features

- User authentication (Login & Signup)
- Shoe product listing with details
- Add to cart functionality
- Persistent cart using cache memory
- Responsive design for desktop and mobile

## Technologies Used

- React.js
- HTML, CSS, JavaScript
- Fetch API/Axios
- LocalStorage/SessionStorage for caching
- External Shoe Database API (if applicable)

## Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/your-username/shoe-store.git
   ```
2. Navigate to the project directory:
   ```sh
   cd shoe-store
   ```
3. Install dependencies:
   ```sh
   npm install
   ```
4. Create a `.env` file and add necessary configurations:
   ```sh
   REACT_APP_API_KEY=your_api_key_here
   ```
5. Start the development server:
   ```sh
   npm start
   ```

## Usage

1. Open the application in your browser at `http://localhost:3000`
2. Register or log in to your account
3. Browse available shoes and view details
4. Add items to the cart
5. View cart and proceed to checkout
6. Cache memory ensures cart persistence

## Deployment

To deploy the project, run:

```sh
npm run build
```

Then deploy the `build` folder to a hosting service like Netlify, Vercel, or GitHub Pages.
